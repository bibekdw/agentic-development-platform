# Portfolio evidence plan

Do not claim autonomous delivery until a GitHub workflow log proves it. Collect:

- Public architecture diagram and threat model.
- Baseline build/CI logs for each sample repository.
- One accepted Issue → OpenSpec proposal → agent-authored draft PR demonstration.
- An intentionally failing CI test plus two-attempt auto-repair / escalation result.
- One coordinated cross-repo change manifest pinning all revisions.
- Integration smoke output for the exact tested versions.
- A table of human intervention minutes, CI/runtime cost, accepted PRs, defect/revert incidents.

Publish real evidence, including failures; avoid fabricated productivity percentages or unverified security claims.
